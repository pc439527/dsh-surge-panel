# Surge 系统监控面板

![Surge 系统监控面板](preview.zh.svg)

参照原项目 `surge-lan-console` 适配的 DSH 原生插件。数据全部来自本机 / 局域网内 Surge 的 HTTP API（本机 `X-Key` 由 Host 读取；手动输入的密钥仅在测试或保存时提交给 Host，已保存的密钥不会回传到浏览器），不伪造任何指标。

## 三个页签

- **概览**：下载/上传速度、会话流量、运行时长、活动连接（支持展开「最近请求」明细）、带 Y 轴刻度与悬浮提示的流量趋势图、按实时速率排序的 LAN 设备总览、网络环境、节点流量与可展开的最近事件；顶栏提供当前连接快速切换弹窗、自动刷新暂停/恢复按钮与加载态手动刷新按钮。
- **设备管理**：多 Surge 实例（连接）的增删改查、设为当前、「保存并设为当前」、卡片内联连通性测试，以及 Fleet 汇总（在线设备数、活动请求、总下载/上传）。首项固定为「本机 Surge」，由 Host 从本机 Surge 配置中按修改时间优先发现，并展示真实的在线/离线状态、地址/端口、延迟与吞吐。
- **设置**：外观（跟随系统 / 浅色 / 深色，仅作用于本面板）、轮询间隔、趋势采样点数、设备/事件显示上限、暂停轮询、当前连接信息、API 诊断（逐端点状态/延迟/响应结构，支持窄屏横向滚动）、关于与带确认反馈的恢复默认。

## 相对原项目恢复的功能

| 原项目功能 | 本插件的 DSH 原生等价实现 |
| --- | --- |
| 连接管理（ConnectionsPage，多实例 CRUD / 切换 / 测试） | 「设备管理」页签 + Host 私有存储 |
| 设备总览（FleetPage，跨实例在线状态与吞吐汇总） | 「设备管理」Fleet 统计条 + 每连接状态徽标 |
| 设置（SettingsPage 外观 / 当前连接 / 关于） | 「设置」页签，偏好存于浏览器 localStorage |
| API 诊断（Settings / API Diagnostics 逐端点检查） | 「设置」→ API 诊断表格 |

偏好与连接分离存储：偏好在浏览器 `localStorage`；连接元数据与 API Key 由 Host 保存在 `~/.dsh/surge-panel-connections.json`（明文 JSON，权限 600）。连接列表只返回 `hasKey` 标记及连接信息、CA 证书，不返回已保存的密钥。选择非本机连接后，概览与诊断指向该实例；Fleet 始终汇总全部连接，包括本机。

## 1.2.0 更新亮点

- **只读详情端点与脱敏**：新增 `/surge-api/detail` 路由，按类型返回规则、策略、模块、DNS 缓存、最近请求、设备、节点、事件与当前配置的有限原始字段。详情按需读取，支持关键词搜索、状态/类别筛选、按 ID 定位与游标分页（单页上限 128 KiB）。
- **凭据安全**：详情与快照中的 URL 去除用户信息、查询参数与片段；已保存的 API 密钥以 `*` 遮盖；Bearer、Cookie、密码、API Key 等凭据样式内容一律不回传，事件与配置仅保留安全摘要。
- **诊断交互**：每个诊断端点可展开查看 HTTP 状态与错误原因，并可一键复制整份诊断报告；窄面板内请求和诊断表格改为纵向条目。
- **连接切换与 Fleet**：当前连接弹窗补齐键盘导航与焦点管理，加载/切换失败有明确提示；Fleet 支持按在线状态筛选与单实例详情。
- **测试**：回归测试从 30 项增加到 37 项，覆盖详情分页、脱敏、连接切换隔离以及版本/词典/打包清单一致性。

## 1.1.2 更新亮点

- **fnOS 子路径网关兼容**：前端 `api()` 自动识别 `window.__FNOS_GATEWAY_CONFIG__.prefix` 与 `<base href>` 前缀，在 fnOS（`/app/fn-deepseek-harness`）等反向代理子路径部署下 `/surge-api/*` 零配置直通。
- **概览与图表增强**：流量趋势图新增 Y 轴刻度、悬浮十字准星与数值提示，量程随当前可见曲线动态计算并统一使用二进制速率换算（B/s ~ GB/s）；LAN 设备按实时速率与会话总流量排序并在行内展示实时速率，切换更稳定；活动连接卡片支持展开「最近请求」明细表；最近事件支持点击展开查看全文。
- **设备管理与顶栏交互**：本机 Surge 卡片接入实时 Fleet 状态（在线/离线、地址、延迟、吞吐与错误原因）；修复删除确认按钮文案与危险态样式，删除正在编辑的连接时自动关闭编辑表单；测试结果内联展示在对应卡片内；表单支持原生 `<form>` 提交（`Enter` / `Esc`）、前置校验与「保存并设为当前」；顶栏新增当前连接快速切换弹窗与暂停/恢复快捷按钮。
- **结构化错误码与可访问性**：Host 全部错误与状态返回结构化 `code`（并在离线时保留 `activeConnection`），前端按当前语言本地化映射；优化浅色模式主按钮对比度（`#ffffff` on `#be4d27`，满足 WCAG AA）；补齐 `tablist`/`tab`/`tabpanel` 与方向键导航、`aria-labelledby`、`aria-pressed` 与诊断表格横向滚动容器。
- **Host 与安全加固**：CA 证书改用 `crypto.X509Certificate` 校验；补齐 IPv6 映射云元数据地址拦截（`::ffff:169.254.169.254`）；删除不存在的连接返回 `404`；插件卸载时清空全部运行时缓存并限制响应缓存条目上限；本机发现按配置修改时间降序优先；收紧 `package.json` `files` 白名单。

## 1.1.1 可靠性基础

- **连接与采样隔离**：切换连接或修改配置后清空趋势采样；迟到响应会被取消或丢弃。Host 在采集期间检测配置版本变化，防止旧实例数据标成新实例。
- **有界请求**：Surge 请求设置总时限，响应中断、异常关闭、错误与超过 16 MiB 均会结束请求。浏览器请求也有超时和卸载取消；提交体仅接受 JSON 对象，限制 64 KiB 和 10 秒。
- **原子保存**：通过权限 600 的独占临时文件与重命名保存连接，成功后才更新内存状态；写盘失败明确报错，保留原连接和密钥。损坏的存储不会被静默覆盖。
- **HTTPS 验证**：校验证书及主机名；自签或私有 CA 可在 HTTPS 连接中填写 PEM 格式 CA 证书（上限 16 KiB，通过 `X509Certificate` 校验）。自动发现的本机 HTTPS 若不受信任，请添加手动 HTTPS 连接并配置 CA。主机字段只填域名或 IP，端口单独填写，支持 IPv6。
- **按需轮询与共享缓存**：仅在面板挂载、页面可见且未暂停时自动采集。上次采集结束后再安排下一次，避免请求堆积。Host 合并并发快照与端点请求；策略、模块、规则、配置成功结果缓存 60 秒，其余成功结果缓存 1 秒，失败结果缓存 1 秒。本机发现结果缓存 30 秒。设备管理的 Fleet 在进入页签或手动刷新时更新，并发探测最多 4 个实例。
- **准确反馈**：可选端点失败时标记数据不可用，或展示上次成功数据及时间；不将失败当作零值或空列表。Fleet 活动请求不完整时显示 `—`，吞吐量仅汇总本次成功响应的实例。连接加载、测试、保存和诊断错误会显示在面板内。

## 开发验证

运行 `npm run check` 检查 Host 与 Client 语法，运行 `npm test` 执行 30 项回归测试（覆盖 Host 全路由、IPv6/SSRF 拦截、X509 CA 校验、本机发现排序、设备排序与最近请求、中英词典/版本号/打包清单一致性等）。测试使用隔离的存储和传输替身，不读取实际密钥、不访问真实 Surge，也不模拟 React 或浏览器布局。真实证书握手、Surge 版本兼容性及界面布局仍需在实际环境验收。

## 界面修复

- **流量趋势横轴**：不再为每个采样点渲染一个时间标签（此前最多 48 个 `13:37` 挤在一起并溢出容器），改为从真实标签序列均匀取最多 6 个刻度（`HH:MM:SS` 带秒），容器 `overflow:hidden`、标签 `white-space:nowrap`，窄屏自动隐藏偶数刻度。
- **最近事件**：相同（级别 + 文本）事件合并为一行并显示 `×N` 计数，单行省略号 + 悬停查看全文、时间靠右，避免同一错误刷屏导致的细碎换行。

## 说明

原项目的「立即锁定控制台」「通知中心 / 后台自动化」「MitM/Rewrite 等功能开关」「加密 Vault」「演示模式（伪造数据）」依赖独立的 Node Core、SQLite、系统通知与后台任务层；本插件为只读 DSH 原生面板，不内嵌这些后端能力，也不伪造数据。其余只读监控功能均可用。
