# Surge 系统监控面板

![Surge 系统监控面板](preview.zh.svg)

参照原项目 `surge-lan-console` 适配的 DSH 原生插件。数据全部来自本机 / 局域网内 Surge 的 HTTP API（本机 `X-Key` 由 Host 读取；手动输入的密钥仅在测试或保存时提交给 Host，已保存的密钥不会回传到浏览器），不伪造任何指标。

## 三个页签

- **概览**：下载/上传速度、会话流量、运行时长、活动连接、流量趋势、LAN 设备总览、网络环境、节点流量与最近事件。
- **设备管理**：多 Surge 实例（连接）的增删改查、设为当前、连通性测试，以及 Fleet 汇总（在线设备数、活动请求、总下载/上传）。首项固定为「本机 Surge」，由 Host 从本机 Surge 配置中发现。
- **设置**：外观（跟随系统 / 浅色 / 深色，仅作用于本面板）、轮询间隔、趋势采样点数、设备/事件显示上限、暂停轮询、当前连接信息、API 诊断（逐端点状态/延迟/响应结构）、关于与恢复默认。

## 相对原项目恢复的功能

| 原项目功能 | 本插件的 DSH 原生等价实现 |
| --- | --- |
| 连接管理（ConnectionsPage，多实例 CRUD / 切换 / 测试） | 「设备管理」页签 + Host 私有存储 |
| 设备总览（FleetPage，跨实例在线状态与吞吐汇总） | 「设备管理」Fleet 统计条 + 每连接状态徽标 |
| 设置（SettingsPage 外观 / 当前连接 / 关于） | 「设置」页签，偏好存于浏览器 localStorage |
| API 诊断（Settings / API Diagnostics 逐端点检查） | 「设置」→ API 诊断表格 |

偏好与连接分离存储：偏好在浏览器 `localStorage`；连接元数据与 API Key 由 Host 保存在 `~/.dsh/surge-panel-connections.json`（明文 JSON，权限 600）。连接列表只返回 `hasKey` 标记及连接信息、CA 证书，不返回已保存的密钥。选择非本机连接后，概览与诊断指向该实例；Fleet 始终汇总全部连接，包括本机。

## 1.1.1 可靠性更新

- **连接与采样隔离**：切换连接或修改配置后清空趋势采样；迟到响应会被取消或丢弃。Host 在采集期间检测配置版本变化，防止旧实例数据标成新实例。
- **有界请求**：Surge 请求设置总时限，响应中断、异常关闭、错误与超过 16 MiB 均会结束请求。浏览器请求也有超时和卸载取消；提交体仅接受 JSON 对象，限制 64 KiB 和 10 秒。
- **原子保存**：通过权限 600 的独占临时文件与重命名保存连接，成功后才更新内存状态；写盘失败明确报错，保留原连接和密钥。损坏的存储不会被静默覆盖。
- **HTTPS 验证**：校验证书及主机名；自签或私有 CA 可在 HTTPS 连接中填写 PEM 格式 CA 证书（上限 16 KiB）。自动发现的本机 HTTPS 若不受信任，请添加手动 HTTPS 连接并配置 CA。主机字段只填域名或 IP，端口单独填写，支持 IPv6。
- **按需轮询与共享缓存**：仅在面板挂载、页面可见且未暂停时自动采集。上次采集结束后再安排下一次，避免请求堆积。Host 合并并发快照与端点请求；策略、模块、规则、配置成功结果缓存 60 秒，其余成功结果缓存 1 秒，失败结果缓存 1 秒。本机发现结果缓存 30 秒。设备管理的 Fleet 在进入页签或手动刷新时更新，并发探测最多 4 个实例。
- **准确反馈**：可选端点失败时标记数据不可用，或展示上次成功数据及时间；不将失败当作零值或空列表。Fleet 活动请求不完整时显示 `—`，吞吐量仅汇总本次成功响应的实例。连接加载、测试、保存和诊断错误会显示在面板内。

## 开发验证

运行 `npm run check` 检查 Host 与 Client 语法，运行 `npm test` 执行回归测试。测试使用隔离的存储和传输替身，不读取实际密钥、不访问真实 Surge，也不模拟 React 或浏览器布局。真实证书握手、Surge 版本兼容性及界面布局仍需在实际环境验收。

## 界面修复

- **流量趋势横轴**：不再为每个采样点渲染一个时间标签（此前最多 48 个 `13:37` 挤在一起并溢出容器），改为从真实标签序列均匀取最多 6 个刻度（`HH:MM:SS` 带秒），容器 `overflow:hidden`、标签 `white-space:nowrap`，窄屏自动隐藏偶数刻度。
- **最近事件**：相同（级别 + 文本）事件合并为一行并显示 `×N` 计数，单行省略号 + 悬停查看全文、时间靠右，避免同一错误刷屏导致的细碎换行。

## 说明

原项目的「立即锁定控制台」「通知中心 / 后台自动化」「MitM/Rewrite 等功能开关」「加密 Vault」「演示模式（伪造数据）」依赖独立的 Node Core、SQLite、系统通知与后台任务层；本插件为只读 DSH 原生面板，不内嵌这些后端能力，也不伪造数据。其余只读监控功能均可用。
